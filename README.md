# InsureTech - Архитектурный проект (Спринт 6)

Данный репозиторий содержит проектную работу по архитектурному проектированию для компании InsureTech в рамках 6-го спринта курса.

## Структура проекта

Репозиторий состоит из шести заданий:

- **Task1** — Проектирование технологической архитектуры
- **Task2** — Динамическое масштабирование контейнеров в Kubernetes
- **Task3** — Переход на Event-Driven архитектуру
- **Task4** — Проектирование процесса оформления ОСАГО
- **Task5** — Проектирование GraphQL API для сервиса client-info
- **Task6** — Настройка Rate Limiting с помощью Nginx
