# Task6 — Настройка Rate Limiting в Nginx

## Описание задачи

В рамках задания настроено ограничение количества запросов на уровне Nginx для защиты API от превышения допустимой нагрузки со стороны отдельных партнёров.

Ограничение:

- Максимум 10 запросов в минуту от одного клиента (на основе IP).
- При превышении лимита возвращается HTTP статус 429 (Too Many Requests).

---

## Используемое решение

Для реализации использованы стандартные директивы Nginx:

- `limit_req_zone` — определяет хранилище для отслеживания количества запросов.
- `limit_req` — применяет ограничение на конкретные location.
- `limit_req_status` — определяет код возврата при превышении лимита.

---

## Ключевые параметры конфигурации

- Хранилище лимитов:

```nginx
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/m;
```

- Ограничение на location:

```nginx
limit_req zone=api_limit burst=5 nodelay;
limit_req_status 429;
```

- Ограничение применяется ко всем входящим HTTP-запросам в location `/`.

---

## Итоговый результат

- Ограничение нагрузки успешно ограничивает партнёрский трафик.
- При превышении лимита клиенты получают ответ с HTTP 429.
- Система защищена от перегрузок и неконтролируемых всплесков активности со стороны отдельных партнёров.

---
